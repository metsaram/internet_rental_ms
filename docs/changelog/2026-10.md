## [2026-10-28]
### Added
- Reusable `ActionMenu` component for Data Tables (`src/components/shared/action-menu.tsx` & re-exported from `data-table.tsx`):
  - Responsive action partitioning rules:
    - 1–3 actions (Desktop/Tablet): All rendered as visible buttons.
    - 1–2 actions (Mobile): All rendered as visible buttons.
    - More than 2 actions (Mobile): Primary action visible as a button, remaining actions in a 3-dot (More) menu.
    - 4–6 actions (Desktop): 1–3 highest-priority actions as visible buttons (default: 2, configurable via `maxVisibleDesktop`), remaining actions in a 3-dot (More) menu.
    - 7+ actions: 3-dot menu with actions organized into logical sections (`General`, `Management`, `Danger Zone` / custom groups).
  - Action prioritization via `priority?: number` (ascending order) and `isPrimary?: boolean`.
  - Explicit placement override via `display?: "auto" | "visible" | "menu"`.
  - Built-in confirmation dialog interception (`confirmation?: ActionConfirmationConfig | boolean`), triggering a `ConfirmDialog` before invoking `onClick`.
  - Accessible tooltip integration on visible buttons displaying action labels or `disabledReason`.
  - Table row click isolation: clicks on action buttons or the 3-dot menu invoke `e.stopPropagation()` by default.
  - Integrated across data table views (`branches.tsx`, `shops.tsx`, `invoices.tsx`, `contracts.tsx`, `plans.tsx`, `services.tsx`).
- Theme-adaptive reduced button backgrounds:
  - Added `subtle` and `destructive-subtle` variants to `Button` (`src/components/ui/button.tsx`) using `bg-primary/10` and `bg-destructive/10`.
  - Updated `ActionMenu` visible buttons to use reduced background tints (10–15% opacity) instead of heavy 100% solid filled blocks in table rows.
  - Added `buttonStyle?: "subtle" | "ghost"` prop to `ActionMenuProps` (defaults to `"subtle"`).
  - Replaced hardcoded Tailwind colors with theme tokens (`text-primary`, `bg-primary/10`, `text-destructive`, `bg-destructive/10`, `text-muted-foreground`, `hover:bg-accent/60`) for full cross-theme compatibility across light, dark, and custom palettes.
- Mobile responsive column sizing in `DataTable`:
  - Automatically sets column widths to `minWidth` on mobile viewports (< 768px via `useIsMobile()`) to prevent horizontal compression and text clipping.
  - Standardized `width`, `minWidth`, and `maxWidth` across all table view columns.
  - Removed deprecated `hideOnMobile` property (replaced by Column Chooser).
- Added unit test suite in `test/action-menu.test.tsx` (10 tests passing, covering responsive breakpoints, overflow partitions, confirmation dialogs, event isolation, reduced backgrounds, and theme tokens).
