## [2026-10-22]
### Added
- Centralized Global Validator service and utility (`src/lib/global-validator.ts` and `src/lib/validation.ts`):
  - Converts code inputs to UPPERCASE.
  - Blocks all special characters by default on code inputs (allowing only `_` and `-` as exceptions).
  - Enforces a maximum length of 100 characters on all code fields (`MAX_CODE_LENGTH = 100`).
  - Preserves standard casing, spaces, and punctuation on all non-code text inputs (names, addresses, notes, etc.).
- Enhanced UI `<Input />` component with `isCode` prop, `maxLength={100}`, and code-field auto-detection: applies uppercase and symbol blocking exclusively to code fields (`code`, `serviceCode`, `contractNumber`, `invoiceNumber`, `reference`, etc.) while leaving regular inputs untouched.
- Updated API layer (`parseJsonBody` in `src/lib/session.ts`) to validate code fields specifically, rejecting invalid characters or length > 100 with 400 `ValidationError`.
- Extended Prisma client in `src/lib/db.ts` to sanitize, truncate to 100 chars, and uppercase code fields prior to persistence across all models.
- Updated Excel import coercion in `src/lib/import-fields.ts` to validate code fields on ingestion.
- Added comprehensive unit test suite in `scripts/test-global-validator.ts` (102/102 tests passing).
- Configured Vitest testing infrastructure (`vitest`, `@vitest/coverage-v8`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`):
