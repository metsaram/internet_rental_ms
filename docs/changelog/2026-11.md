# Changelog — November 2026

## [2026-11-01]
### Added
- **Dark Mode App Icons for iOS & Web App UI Consistency** — Resolved poor logo visibility in iOS Dark Mode and dark theme environments by introducing high-contrast dark mode icon assets matching `logo-dark.png` (`#30b784` / `#30b785`):
  - **`public/logo-icon-dark.png`**: High-resolution 512×512 transparent PNG featuring the vibrant emerald NetRent planetary "N" emblem (`#30b784`), matching `public/logo-dark.png`.
  - **`public/icon-dark.png` & `src/app/icon-dark.png`**: 512×512 web favicon with the vibrant emerald emblem for dark browser tabs.
  - **Resized Web Icons**: Generated `icon-192-dark.png`, `icon-32-dark.png`, and `icon-16-dark.png`.
  - **iOS Apple Touch Icons (`public/apple-icon.png` & `public/apple-icon-dark.png`)**: 180×180 PNGs with dark background (`#161d19`, matching NetRent's dark viewport `themeColor`) and centered high-contrast emerald logo (`#30b784`), ensuring the icon remains legible in iOS 18+ Home Screen Dark Mode and Tinted Mode without dark-on-dark washout.
  - **`public/favicon-dark.ico` & `src/app/favicon-dark.ico`**: Multi-resolution (16×16, 32×32, 48×48) ICO container embedding the vibrant `#30b784` emerald emblem for browsers that request `.ico` favicons in dark mode.
  - **`src/app/layout.tsx` Metadata**: Enhanced `metadata.icons` with media queries for `(prefers-color-scheme: dark)`:
    - `icon`: `/favicon.ico` (any) + `/icon.png` (light), and `/favicon-dark.ico` (any) + `/icon-dark.png` (dark).
    - `apple`: `/apple-icon.png` (dark/high-contrast default) and `/apple-icon-dark.png` (dark).
  - **App UI Dark Mode Switching**:
    - **`SidebarBrand` (`src/components/app-shell.tsx`)**: Renders `logo-icon.png` with `dark:hidden` in light mode and `logo-icon-dark.png` with `hidden dark:block` in dark mode.
    - **`LoginView` (`src/components/views/login.tsx`)**: Updated desktop branding header and mobile header to toggle between light and dark logo icons.
  - **Verification**: Created `test/dark-mode-icons.test.tsx` asserting dominant color parity between `logo-icon-dark.png` and `logo-dark.png`, 180×180 dimensions and contrast for `apple-icon.png`, `favicon-dark.ico` ICO structure, and metadata declarations (4 tests passed).
