# Task Log — 2026-10-23

## [2026-10-23T19:44:00+07:00] Fix Session Timeout Reset After Re-Authentication

- **Task description**: Fix immediate session timeout occurring upon re-authentication after an inactivity session expiration.
- **Root cause**:
  1. `useIdleTimeout`'s timeout handler (`handleTimeout`) called `signOut({ redirect: false })` without clearing the cross-tab activity timestamp stored in `localStorage` (`netrent_last_active_timestamp`).
  2. The login screen (`src/components/views/login.tsx`) did not reset or clear the stored activity timestamp upon successful sign in.
  3. When the user re-authenticated and entered `<AppShell>`, `useIdleTimeout` mounted and initialized its `lastActiveRef` from `localStorage` using only `ts <= Date.now()`. It accepted the stale, expired timestamp from 15+ minutes prior.
  4. On the very first 1-second interval tick, elapsed time exceeded `idleTimeMs`, immediately triggering automated logout again.
- **Context used**:
  - `src/lib/idle-timeout-config.ts`
  - `src/hooks/use-idle-timeout.ts`
  - `src/components/views/login.tsx`
  - `src/components/app-shell.tsx`
  - `src/components/shared/command-palette.tsx`
  - `test/idle-timeout.test.tsx`
  - `tests/auth/login.spec.ts`
- **Output generated / modified**:
  - `src/lib/idle-timeout-config.ts`: Defined and exported `IDLE_STORAGE_KEY`, `resetIdleTimeoutStorage()`, and `clearIdleTimeoutStorage()`.
  - `src/hooks/use-idle-timeout.ts`:
    - Updated `handleTimeout` and `logoutNow` to call `clearIdleTimeoutStorage()`.
    - Added freshness check `now - ts < idleTimeMs` in `useEffect` initialization so stale timestamps are discarded and reset to `Date.now()`.
    - Reset internal state flags (`isTimedOutRef.current = false`, `isWarningOpen = false`, `remainingSeconds`) whenever `enabled` activates.
  - `src/components/views/login.tsx`: Called `resetIdleTimeoutStorage()` upon successful credentials authentication.
  - `src/components/app-shell.tsx` & `src/components/shared/command-palette.tsx`: Added `clearIdleTimeoutStorage()` to explicit sign-out triggers.

  - `tests/auth/login.spec.ts`: Added Playwright E2E verification confirming that re-authenticating after an expired timestamp resets the idle timer and keeps the session active.
