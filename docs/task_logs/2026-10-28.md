- **Behavior Matrix**:
  - **1–3 actions (Desktop/Tablet)**: All visible buttons.
  - **1–2 actions (Mobile)**: All visible buttons.
  - **More than 2 actions (Mobile)**: Primary action visible as a button, remaining actions in a 3-dot (More) menu.
  - **4–6 actions (Desktop)**: Top 1–3 highest-priority actions as visible buttons (default 2, configurable via `maxVisibleDesktop`), remaining actions in a 3-dot (More) menu.
  - **7+ actions**: 3-dot (More) menu with actions organized into logical sections (`General`, `Management`, `Danger Zone` / custom groups).
- **Context used**:
  - `src/components/shared/action-menu.tsx`

    - Disabled state support with `disabledReason` displayed inside accessible tooltips.
