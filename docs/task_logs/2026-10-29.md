- **Task description**:
  Investigate and fix why the "Columns" chooser button was not wrapping onto the same row as other filter items (like "Newest first") on small screens, instead appearing isolated on its own row below.

- **Root cause**:
  1. In `src/components/shared/data-table.tsx`, `{toolbar}` was wrapped inside an intermediate `<div className="flex flex-wrap gap-2">{toolbar}</div>`.
  2. Because of this nested container, all filter elements passed via `toolbar` were confined inside their own flex block. When the filter elements wrapped onto multiple lines (e.g., Row 1: `Select Status` + `Select Provider`; Row 2: `Newest first`), the toolbar container's width was locked to the width of the first line (~344px).
  3. The `Columns` button, being a sibling to that container rather than a sibling to the individual filters, could not enter the toolbar container to occupy the empty space on Row 2 next to `Newest first`, forcing it down to Row 3.
  4. In `src/components/views/services.tsx`, `toolbar` was additionally wrapped in another `<div className="flex flex-wrap items-center gap-2">` instead of a React Fragment.

- **Output generated / modified**:
  1. **`src/components/shared/data-table.tsx`**:

     - Changed flex alignment on outer container to `sm:items-start` and inner toolbar container to `items-start`, ensuring the search input and filter items remain aligned to the top even when filters wrap across multiple rows.
