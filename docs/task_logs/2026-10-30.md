## Task 3: Invoice Schedule & Finance Structure & Calculation Parity with Contract
- **Problem**: Invoices had a separate quick-fill box and manual subtotal calculation. User requested the EXACT same structure and calculation from `ContractForm` (`2. Schedule & Duration`, `3. Financial Terms & Billing`, and `Live Cost Projection`).
- **Solution**:
  1. Replaced the separate period dates & quick-fill box in `InvoiceForm` (`src/components/views/invoices.tsx`) with the exact contract form structure:
     - **Card: 2. Schedule & Duration**: `Start date *` (DatePicker), `Duration (months) *` (Input number), `Free months` (Input number, hint: "Zero-fee extension"), and `End date` (disabled DatePicker, hint: "Auto-calculated (extended by free months)").
     - **Card: 3. Financial Terms & Billing**: `Agreed Monthly fee *` (Input number), `Currency` (Input 3 chars), `Billing cycle` (Select: Yearly, Monthly, Quarterly, Semi-annual).
     - **Card: 4. Live Cost Projection**: Billable Months (`${paidMonths} of ${totalMonths}m (${freeMonths}m free)`), Scheduled Total (`formatMoney(scheduled, cur)`), Effective Monthly (`formatMoney(effective, cur)/mo`).
     - **Adjustments & Total**: Tax / VAT, Discount, and Total Payable (`Math.max(0, scheduled + tax - discount)`).
  2. Integrated identical contract calculation logic:
     - `totalMonths = Math.max(0, duration + freeMonths)`
     - `endDate = startDate + totalMonths` (UTC-safe to prevent timezone drift)
     - `paidMonths = Math.max(0, duration)` (free months cost $0)
     - `scheduled = monthlyFee * paidMonths` (auto-syncs `subtotal = scheduled`)
     - `effective = totalMonths > 0 ? scheduled / totalMonths : 0`
     - `total = Math.max(0, scheduled + tax - discount)`
  3. Auto-prefill on selection:
     - Selecting a Contract: prefills `startDate`, `duration`, `freeMonths`, `monthlyFee`, `currency`, `billingCycle`.
     - Selecting an Installed Service: prefills `startDate`, `duration`, `freeMonths`, `monthlyFee`, `currency`, `billingCycle`.
  4. Updated `test/invoice-schedule.test.tsx` to assert exact timeline calculation, free months extension, scheduled fee, effective dilution, and comprehensive `isFormValid` validation. All 28 tests passing.

## Task 4: Auto-Calculate Tax Default 10% (Price Excluded)
- **Problem**: User requested: "Auto calculate tax default 10% (price excluded)".
- **Solution**:

     - Added `taxRate` state (defaults to `10%`).
     - Added `taxManual` state (defaults to `null` on new invoice, allowing automatic calculation; retains manual amount if user overrides or when editing an existing invoice).
