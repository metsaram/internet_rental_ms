# Task Log — 2026-11-01

## Task: iOS Dark Mode App Icon & Dark Theme Logo Color Standardization

### User Request
"check icon for IOS app when dark mode it hard to see logo color on ios 26up and use theme dark, the logo color should same @public/logo-dark.png"

### Root Cause Analysis
1. **iOS Home Screen Inversion**: The previous `apple-icon.png` (180×180) featured a solid white background with a dark green emblem (`#015d3f`). When added to an iOS device running Dark Mode (introduced in iOS 18+ and applicable across modern iOS), iOS darkens the background to dark charcoal/black (`#1c1c1e`), resulting in an almost invisible dark-on-dark emblem (contrast ratio 2.14:1).
2. **App UI in Dark Theme**: In `src/components/app-shell.tsx` and `src/components/views/login.tsx`, the logo emblem was statically linked to `/logo-icon.png` (dark green `#005c3e`), which blended into the dark emerald containers (`dark:bg-emerald-950/40`), failing to use the vibrant emerald green (`#30b784`) already established in `public/logo-dark.png`.

### Implementation Details
1. **Asset Generation via Sharp**:
   - `public/logo-icon-dark.png` (512×512): High-resolution transparent PNG with dominant color `#30b784` (RGB: 48, 183, 133).
   - `public/icon-dark.png` & `src/app/icon-dark.png` (512×512): Web favicon for dark mode browser tabs.
   - Resized icons: `public/icon-192-dark.png`, `public/icon-32-dark.png`, `public/icon-16-dark.png`.
   - `public/apple-icon-light.png`: Preserved original white-background icon.
   - `public/apple-icon.png` & `public/apple-icon-dark.png` (180×180, also copied to `src/app/`): Rendered on `#161d19` background (NetRent dark themeColor) with centered 130×105 `#30b784` emblem, boosting contrast ratio to 6.73:1 (exceeds WCAG AAA).
   - `public/favicon-dark.ico` & `src/app/favicon-dark.ico`: 3-size (16×16, 32×32, 48×48) ICO container containing embedded PNG icons with dominant color `#30b784`.
2. **Next.js Metadata Integration (`src/app/layout.tsx`)**:
   - Updated `metadata.icons` to include conditional `media: "(prefers-color-scheme: dark)"` variants for both standard `icon` (`favicon.ico` + `icon.png` in light mode; `favicon-dark.ico` + `icon-dark.png` in dark mode) and Apple touch `apple` icons (`apple-icon.png` and `apple-icon-dark.png`).
3. **Responsive Dark Mode UI Toggles**:
   - `src/components/app-shell.tsx`: Updated `SidebarBrand` to render `logo-icon.png` with `dark:hidden` and `logo-icon-dark.png` with `hidden dark:block`.
   - `src/components/views/login.tsx`: Updated desktop header and mobile header to toggle between light and dark logo icons.
4. **Automated Verification**:
   - Created `test/dark-mode-icons.test.tsx` verifying file existence, color parity against `logo-dark.png`, 180×180 dimensions, background darkness, `favicon-dark.ico` binary ICO structure and embedded colors, and layout metadata definitions.
   - Ran `bun run test:run test/dark-mode-icons.test.tsx` (all 4 tests passed in 26ms).
