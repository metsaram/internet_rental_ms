## Task: Fix HTML Validation Hydration Error (`<div>` inside `<p>` in DetailGrid)

### Root Cause
In `src/components/views/invoices.tsx`, `DetailGrid` rendered row values inside `<p className="text-sm">{value}</p>`. In `InvoiceDetailSheet`, the Branch, Shop, and Provider rows returned `<div key="...">` containing the entity name and code. In HTML, `<div>` is a block-level element and cannot be a descendant of paragraph element `<p>`, causing React hydration errors.

### Fix
1. In `src/components/views/invoices.tsx`:
   - Changed `DetailGrid` row value container from `<p className="text-sm">` to `<div className="text-sm">`.
   - Changed entity wrapper elements for Branch, Shop, and Provider from `<div key="...">` to `<span key="..." className="block">`.
2. In `src/components/views/shops.tsx`:
   - Updated `DetailGrid` to use `<div className={cn("text-sm")}>{value}</div>` instead of `<p>`.
3. Verified full test suite passes (32 test files, 294 tests).
