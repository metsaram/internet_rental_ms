# Internet Rental Management System --- Phase Prompt Pack

This pack contains one Markdown prompt per implementation phase for a
Next.js App Router + TypeScript + Prisma + PostgreSQL application
deployed on Vercel.

## Use it

1.  Give the coding agent `00-GLOBAL-IMPLEMENTATION-RULES.md` first.
2.  Execute `PHASE-00` through `PHASE-19` in order, one phase per task.
3.  Review the completion report and acceptance criteria before
    continuing.
4.  Commit working code after each phase.
5.  Do not ask the agent to implement every phase in one run.

## Domain principles

-   Provider = Internet vendor.
-   Plan = reusable package/catalog offering.
-   Service = actual installed connection.
-   Contract = commercial agreement and agreed price terms.
-   Invoice = bill for a period.
-   Payment = money paid and allocated to invoice(s).

Do not force an Excel layout to become the database design. Treat
spreadsheets as import/export formats. The source workbook has not been
inspected in this conversation, so field mappings should be verified
against the actual workbook when available.
